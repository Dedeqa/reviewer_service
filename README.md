# Reviewer Service (skeleton)
Лёгкий сервис назначения ревьюеров для PR.
## Как запустить
1. Убедитесь, что установлен Docker & docker-compose.
2. `make up` — поднимет Postgres и приложение (порт 8080).
## Что внутри
- API на Go (см. `cmd/server/main.go`)
- PostgreSQL схема — `migrations/001_create_schema.sql` (подключается при
  инициализации контейнера через `docker-entrypoint-initdb.d`).
## Замечания
- Для простоты все обработчики находятся в `main.go`.
- В качестве драйвера DB используется `database/sql` + `github.com/lib/pq`.
- При создании PR автоматически назначаются до 2 активных ревьюверов из
  команды автора, исключая автора.
- Переназначение заменяет одного ревьювера случайным активным участником
  команды заменяемого ревьювера.
- После `MERGED` изменение списка ревьюверов запрещено.
